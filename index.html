The hypercube graph Q7 has vertex set {0,1}n (binary strings of length n). Two vertices are adjacent if and only if they differ in exactly one bit (Hamming distance 1). Q0 is a single vertex.

Vertices
128
Edges

Degree
7
  • Equal-color edges flip the same bit — one dimension.
  • The graph is bipartite (partition by parity of the number of 1-bits).
  • Hamilton paths correspond to Gray codes on n bits.
  • This drawing is a 2D projection of Qn, not a literal view of n-space.

Hover a vertex for its binary address even when labels are off. Bits read left→right as dim n … dim 1 (rightmost bit flips with dim 1 edges).
